# Kapok Family Status Portal

A minimal public-facing lookup page: enter a patient ID to see whether
they've been marked as rescued and when their status last updated.

This intentionally does not show precise location — only verified
responders (via the main dashboard) can see exact coordinates.

## Run locally
1. Make sure the backend is running on port 3000 (see root README).
2. `npm install`
3. `npm run dev`
4. Open the printed local URL (typically http://localhost:5173)
